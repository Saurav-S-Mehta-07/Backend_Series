Frameword
a Frameword is a set of pre-written code that provides a structure for developing software
applications.

express
A Node.js web application framework that helps us to make web applications
It is used for server side programming.

Four major uses of express:
1. Listen for incomming request
2. Parse request
3. match response with routes
4. response
