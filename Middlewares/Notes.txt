# Middleware

It is an intermediary

request->middleware->response

in Express
middleware in express are functions that come into play
after the server receives the request and before the 
response is sent to the client


## common middleware functions:
* methodOverride
* bodyParser
* express.static
* express.urlencoded

app.use(express.urlencoded({extended:true}));

app.use(express.static(path.join(__dirname, "/pulic")));



##

1. middleware can access req, res object
2. chaining is posible in middleware
3. send a response and can break the chaining


# what do middlewares do?
  Middleware functions can perform the following tasks:
  * Execute any code.
  * Make changes to the request and the reponse objects.
  * End the request-response cycle.
  * Call the next middleware function in the stack.

# our 1st middleware
app.use(middleware)



// middlewares


// works for all paths but continuous load 

app.use(()=>{
    console.log("Hi, I am a middleware")
});

//using req & res object in middleware
app.use((req,res)=>{
    let {q} = req.query
    console.log(q)
    console.log("hi, I'm a middleware");
    res.send("bye");
})


## Using next
the next middleware function is commonly denoted
by a variable named next.

//also for all path but not continuous load call the next
app.use((req,res,next)=>{
    console.log("time: ", Date.now())
    next()
})

If the currect middleware function does not end the request-response
cycle, it must call next() to pass control to the next middleware function

app.use((req,res,next)=>{
    console.log("time: ", Date.now())
    next()
    console.log("after next") // it will also executed but right way to do or write like this
})



## Creating Utility Middleware
logger -> helps to log (useful info console print)
useful info -> request's method(post, get, put, delete, patch), time

app.use((req,res,next)=>{
    req.time = new Date().toString();
    console.log(req.method, req.hostname, req.path, req.time);
    next()
})


# app.use Callback



// this middleware run for all routes as previous
app.use("/",(req,res,next)=>{
    console.log("I'm only / route but I'll run for all")
    next()
})

// this middleware for specific path /random and /random/anything
app.use("/random",(req,res,next)=>{
    console.log("I'm only for random")
    next()
})



// one way to write middleware

app.use("/api",(req,res,next)=>{
    let {token} = req.query
    if(token==="access123"){
       return next();
    }
    res.send("access denied");
})

app.get("/api",(req,res)=>{
    res.send("welcome! these APIs is for free") 
})

// second way to write middleware
const checkToken = (req,res,next)=>{
    let {token} = req.query
    if(token==="access123"){
       return next();
    }
    res.send("access denied");
}

app.get("/api",checkToken,(req,res)=>{
    res.send("welcome! these APIs is for free") 
})
